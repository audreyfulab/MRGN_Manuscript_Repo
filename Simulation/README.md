# Simulation

Simulation study for comparing MRGN, MRPC, and GMAC on synthetic trio data with various types of confounding variables (confounder, intermediate, common child). See the simulation write-up in `Manuscript/scripts/6_6_2023_all_conf_types_simulation_updated_2025.Rmd` for full details.

## Overview

Two simulation scenarios are included:

1. **Standard simulations** (1,500 trios) — 300 trios per causal model (M0–M4), each with 1–15 unknown confounders. Generated by `sim_data.R`.
2. **Many-confounder simulations** (300 trios) — Trios with 15–50 unknown confounders to test method performance under high-dimensional confounding. Generated by `sim_data_with_many_confounders.R`.

## Top-Level Scripts

| File | Description |
|---|---|
| `sim_data.R` | Generates 1,500 simulated trios (300 per model M0–M4) using `simData.from.graph()`. Randomly draws simulation parameters (MAF, SNP effect, mediation effect, noise, number of confounders) and uses real GTEx WholeBlood known covariates plus simulated unknown confounders. |
| `sim_data_with_many_confounders.R` | Same as `sim_data.R` but generates 300 trios with 15–50 unknown confounders per trio for the high-dimensional confounding scenario. |
| `load_results2.R` | Loads and post-processes all simulation results (GMAC cis/trans, MRGN, MRPC). Applies q-value FDR correction to GMAC p-values, translates significance into mediation type labels, and assembles results into comparable data structures. |

## Subfolders

### `data/`

Simulated datasets and processed results for both simulation scenarios.

| Subfolder / File | Description |
|---|---|
| `int_and_child_filtered_data/` | Simulated trio data and inference results for the standard (1–15 confounders) scenario. Contains MRGN/MRPC confounder lists, inference results, and selected-confounder datasets. |
| `many_conf_data/` | Simulated trio data and inference results for the many-confounder (15–50) scenario. Same structure as above. |
| `diagnostics/` | Computation time diagnostics for MRGN and MRPC, including confounder-selection timing data. |
| `support_data_for_write_ups/` | Auxiliary tables and data referenced in write-ups. |
| `*.RData` | Pre-processed combined result tables (GMAC, MRGN, MRPC) across all models and confounder types. |

Both `int_and_child_filtered_data/` and `many_conf_data/` contain an `alpha_01_selected_confs_results/` subfolder with results when confounders are selected using a stricter alpha < 0.01 cutoff instead of the default FDR < 10%.

> **Note:** Several large data files in this folder are excluded via `.gitignore` and must be regenerated locally:
>
> - `int_and_child_filtered_data/confs_mrgn_mrpc_get_conf_out_all.RData`
> - `int_and_child_filtered_data/alpha_01_selected_confs_results/MRGN_15confs_liberal_alpha01_conf_list.RData`
> - `int_and_child_filtered_data/alpha_01_selected_confs_results/MRGN_15confs_liberal_alpha01_conf_output.RData`
> - `int_and_child_filtered_data/alpha_01_selected_confs_results/MRGN_15confs_liberal_alpha01_DATA_W_SELECTED_CONFS.RData`
> - `many_conf_data/alpha_01_selected_confs_results/MRGN_many_conf_liberal_alpha01_DATA_W_SELECTED_CONFS.RData`
> - `many_conf_data/alpha_01_selected_confs_results/MRGN_many_conf_liberal_sel_alpha01_conf_list.RData`
>
> These can be regenerated by running the inference scripts in `results/MRGN/`.

### `results/`

Inference scripts organized by method:

| Subfolder | Files | Description |
|---|---|---|
| `GMAC/` | `GMAC_sim2.R`, `GMAC_many_conf.R` | Runs GMAC cis/trans mediation inference on the standard and many-confounder simulated datasets. |
| `MRGN/` | `MRGN_sim2.R`, `MRGN_sim2_filter_int_child.R`, `MRGN_many_conf.R` | Runs MRGN inference on simulated data. The `filter_int_child` variant filters intermediates and common children before inference. |
| `MRPC/` | `MRPC_sim2.R`, `MRPC_sim2_filter_int_child.R` | Runs MRPC-ADDIS inference on simulated data, with and without intermediate/child filtering. |

### `GMAC_validation_SIM/`

Standalone validation experiment assessing GMAC's Type I and Type II error rates across varying confounder counts (2–15).

| File | Description |
|---|---|
| `simdata_for_gmac_valid_exp_yang_exact.R` | Generates 2,000 trios under Model 0 and Model 1 for each of 7 confounder-count levels (2, 4, 6, 8, 10, 12, 15). |
| `run_GMAC_validation.R` | Runs the GMAC algorithm on the validation datasets and computes Type I error, Type II error, and power at 0.01 and 0.05 significance cutoffs. |
| `gmac_valid_summary_results_table.csv` | Summary results table from the validation experiment. |
| `data/` | Simulated validation datasets. |
| `results/` | GMAC inference outputs for each confounder-count level. |

### `scripts/`

Currently empty — inference scripts are located in `results/` subfolders by method.
